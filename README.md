# 赌徒破产定理 · 一万个赌徒的蒙特卡洛仿真

视频《赌徒破产》的配套代码。视频里出现的每一个数字，都由这里的代码算出：随机种子固定为 **1891**，你在自己电脑上运行，结果会和视频完全一致。

## 运行

```bash
pip install numpy
python 赌徒破产_完整代码.py
```

大约十几秒跑完。Windows 终端如果中文显示乱码，改用 `python -X utf8 赌徒破产_完整代码.py`。

## 文件

| 文件 | 说明 |
|---|---|
| `赌徒破产_完整代码.py` | 完整版，带注释。视频里两张代码卡片（约 2:00、6:10）就是摘自这个文件的第 56–67 行和第 60–77 行 |
| `赌徒破产_评论区精简版.py` | 精简到一千字左右，方便贴在评论区，结果相同 |

把代码里的 `1891` 换成任意整数（比如你的生日），重新运行。具体数字会变，但结论不会：只要不离场，破产只是时间问题。
